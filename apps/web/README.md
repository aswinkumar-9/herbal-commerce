# The customer website (planned)

The customer website starts in a later part. This folder holds its design
rules until then:

- `.claude/skills/landing-page-design/` guides every page of the website and
  the apps. It is adapted from elayadesign/ai-design-skills (MIT), with this
  project's own rules first.
- The shop's look (colours, Poppins, glass, the scrim, motion) is in
  `packages/design`, as `@herbal/design/shop.css` (ADR 0036).

The admin console (`apps/admin`) never follows these rules: its look is glass
and clay (ADR 0035).
